# Smart Compost Machine

An IoT-based Smart Compost Machine that converts organic waste into compost using automation.

## Technologies Used
- ESP32
- DHT22 Sensor
- MQ4 Gas Sensor
- OLED Display
- Relay Module
- Temperature & Humidity Monitoring

## Features
- Automatic drying and heating
- Real-time monitoring
- Sensor-based control
- Smart waste management
